SPATIAL APPLICATION POLICY
- Geometry uses EPSG:25832, with meter coordinate units.
- Area: extensions.ST_Area(room.geom) AS area_m2.
- For this prototype, "nearest" means straight-line centroid distance
  on the same floor.
- Calculate:
  extensions.ST_Distance(
      extensions.ST_Centroid(origin.geom),
      extensions.ST_Centroid(destination.geom)
  ) AS distance_m
- Require destination.floor_id = origin.floor_id.
- Different floors may share identical X/Y coordinates.
- Do not compare 2D distances across floors.
- Exclude destination.id = origin.id when finding another space.
- Order candidates by distance_m, destination.id.
- For nearest-per-origin queries, use correlated LATERAL.
- Inside the lateral subquery:
  filter the destination category and same floor,
  calculate distance_m,
  ORDER BY distance_m, destination.id,
  and LIMIT 1.
- Do not use one outer LIMIT 1 for multiple origins.
- Use CROSS JOIN LATERAL when only origins with matching destinations
  should appear.
- Use LEFT JOIN LATERAL (...) AS nearest ON true when origins without
  destinations must remain.
- Preserve NULL destination fields when no destination exists.
- "Within N meters" uses centroid distance <= N.
- Do not substitute polygon-boundary distance for centroid distance.
- For rooms completely inside a floor section, require:
  section.floor_id = room.floor_id
  AND extensions.ST_Covers(section.geom, room.geom).

EXAMPLE: BROAD CLASSROOM LISTING
User request: List all classroom names in the building.

SELECT
    room.room_number,
    room.room_description AS classroom_name,
    fl.floor_number,
    building.name AS building_name
FROM sample.indoor_space AS room
JOIN sample.floor AS fl ON fl.id = room.floor_id
JOIN sample.building AS building ON building.id = fl.building_id
WHERE room.space_type = 'classroom'
ORDER BY building.name, building.id, fl.floor_number, room.room_number;
