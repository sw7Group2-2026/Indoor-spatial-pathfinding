STRUCTURAL EXAMPLE: NEAREST TOILET FROM A SUPPLIED ROOM
The identifier and floor below are illustrative request values, not
claims about stored data. Replace them with the actual user's values.

User: Assume I am in room R-17 on floor 3. What is the closest toilet?

SELECT
    origin.id AS origin_id,
    origin.room_number AS origin_room,
    nearest.destination_id,
    nearest.room_number AS toilet_number,
    fl.floor_number,
    building.name AS building_name,
    nearest.distance_m,
    nearest.x AS destination_x,
    nearest.y AS destination_y,
    25832 AS srid
FROM sample.indoor_space AS origin
JOIN sample.floor AS fl ON fl.id = origin.floor_id
JOIN sample.building AS building ON building.id = fl.building_id
CROSS JOIN LATERAL (
    SELECT
        destination.id AS destination_id,
        destination.room_number,
        extensions.ST_Distance(
            extensions.ST_Centroid(origin.geom),
            extensions.ST_Centroid(destination.geom)
        ) AS distance_m,
        extensions.ST_X(
            extensions.ST_Centroid(destination.geom)
        ) AS x,
        extensions.ST_Y(
            extensions.ST_Centroid(destination.geom)
        ) AS y
    FROM sample.indoor_space AS destination
    WHERE destination.space_type = 'toilet'
      AND destination.floor_id = origin.floor_id
    ORDER BY distance_m, destination.id
    LIMIT 1
) AS nearest
WHERE origin.room_number ILIKE 'R-17'
  AND fl.floor_number = 3
ORDER BY building.id, fl.id, origin.id;

STRUCTURAL EXAMPLE: SPACES NEXT TO A SUPPLIED CLASSROOM
The identifier below is illustrative, not a claim about stored records.
Use the actual user-supplied identifier and only explicitly supplied filters.

User: Assume I am in classroom R-17. What spaces are next to it?

SELECT
    origin.id AS origin_id,
    origin.room_number AS origin_room,
    neighbor.id AS neighbor_id,
    neighbor.room_number AS neighbor_room,
    neighbor.room_description,
    neighbor.space_type,
    fl.floor_number,
    building.name AS building_name
FROM sample.indoor_space AS origin
JOIN sample.floor AS fl ON fl.id = origin.floor_id
JOIN sample.building AS building ON building.id = fl.building_id
JOIN sample.indoor_space AS neighbor
    ON neighbor.floor_id = origin.floor_id
   AND neighbor.id <> origin.id
WHERE origin.room_number ILIKE 'R-17'
  AND origin.space_type = 'classroom'
  AND extensions.ST_Touches(origin.geom, neighbor.geom)
  AND extensions.ST_Length(
      extensions.ST_Intersection(
          extensions.ST_Boundary(origin.geom),
          extensions.ST_Boundary(neighbor.geom)
      )
  ) > 0
ORDER BY building.id, fl.id, origin.id, neighbor.room_number, neighbor.id;
